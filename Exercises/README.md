# Exercises 💻

This folder contains all my exercises and labs for the PRM393 Flutter course.

## How to run
1. Open a terminal.
2. Navigate to the exercise folder (e.g., `cd exercise1`).
3. Run `flutter pub get`.
4. Run `flutter run`.
